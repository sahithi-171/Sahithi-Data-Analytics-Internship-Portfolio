Task 4 - Data Storytelling & Statistical Validation
---------------------------------------------------
 Overview
----------
This task focused on transforming analytical findings into a compelling business story and validating key insights using statistical testing.

Activities Performed
---------------------
- Created a Business Presentation
- Developed Data Storytelling
- Performed Statistical Validation using T-Test
- Interpreted Statistical Results
- Provided Business Recommendations

 Statistical Test
------------------
- Independent Samples T-Test

Hypothesis
-----------
- H₀: Movies and TV Shows have the same average duration.
- H₁: Movies and TV Shows have different average durations.

Result
------
- T-Statistic: 252.18
- P-Value: < 0.001

Conclusion
-----------
The null hypothesis was rejected, indicating a statistically significant difference between the average durations of Movies and TV Shows.
